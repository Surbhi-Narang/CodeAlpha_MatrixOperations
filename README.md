# CodeAlpha_MatrixOperations
Implementation of basic matrix operations (addition, multiplication, transpose) using C programming.

## 📌 Programs Included

1. Matrix Addition  
2. Matrix Multiplication  
3. Matrix Transpose  

## 🧠 Concepts Used
- 2D Arrays  
- Nested Loops  
- Basic Matrix Logic  

## 🚀 Description

- Matrix Addition: Adds corresponding elements of two matrices  
- Matrix Multiplication: Multiplies two matrices using row-column method  
- Transpose: Converts rows into columns  

## 💻 Files

- matrix_addition.c  
- matrix_multiplication.c  
- matrix_transpose.c  

## 📎 Output
Each program takes user input and displays the result accordingly.
